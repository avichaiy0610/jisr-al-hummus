# ג'יסר א-חומוס — מסמך תכנון

תאריך: 2026-10-16 · אושר על ידי אביחי בשיחה.

## מטרה
אתר סטטי חינמי בעברית (RTL) לכפר ערבי סאטירי ודמיוני, "ג'יסר א-חומוס" (משחק מילים על ג'יסר א-זרקא, בנושא חומוס).
כל עוקב של עמוד האינסטגרם מקבל בית. המבנה בהשראת onlycoolprojects.com/telbatata, אבל כל הקוד והטקסטים נכתבים מאפס.

## אילוצים
- אחסון חינמי בלבד: GitHub Pages, עם פריסה דרך GitHub Actions. אין שירותים בתשלום.
- לא פותחים חשבונות בשם אביחי. את חשבון GitHub ואת הריפו הוא פותח בעצמו.
- שמות המשתמשים של העוקבים הפעילים גלויים באתר, כמו בתל בטטה.
- לא סורקים את אינסטגרם. המקור היחיד הוא קובץ הייצוא הרשמי ("Download your information").
- מתכננים לסדר גודל של עד 200,000 בתים.

## זרימת הנתונים
```
Instagram export (.zip / followers_*.json)
   │  npm run update -- <file> [--push]
   ▼
tools/update.mjs ── parse-export ──► registry.update ──► emit
   │                                   │                  │
   │                         data/registry.json      site/data/{meta.json, r/xx.json, list/NNNN.json}
   ▼
git push ──► GitHub Actions (tests + deploy site/) ──► GitHub Pages
```
- את קובץ הייצוא הגולמי **לא** מכניסים לריפו (`exports/` נמצא ב־gitignore), כי הוא יכול להכיל מידע פרטי נוסף.
  לכן הסקריפט רץ מקומית. Actions רק מריץ בדיקות ומפרסם את `site/`.

## Registry (מקור האמת, `data/registry.json`)
- `residents[k]` הוא בית מספר `k+1`. הרשימה רק מתארכת, ואף רשומה לא נמחקת.
- רשומה פעילה: `{ "u": "name", "t": <ts> }`. רשומה שעזבה: `{ "h": "<sha256 hex>" }`.
  את השם של מי שעזב מוחקים, ושומרים רק את ה־hash שלו כדי שיוכל לקבל את ביתו בחזרה.
- כללי העדכון:
  1. פעיל שלא מופיע בייצוא החדש → הופך לרשומה שעזבה (הבית "נטוש").
  2. עוקב שמופיע בייצוא ותואם hash של רשומה שעזבה → חוזר לאותו בית.
  3. עוקב חדש → מקבל בית בסוף הרשימה. כמה חדשים יחד ממוינים לפי timestamp ואז לפי שם.
  4. הגנה: אם מספר העוקבים בייצוא קטן ביותר מ־50% מהמספר הפעיל, הסקריפט עוצר, אלא אם מוסיפים `--force`.
- `history`: לכל עדכון נשמר `{date, count}`. "יום" בכפר = `history.length`.
- שינוי שם משתמש באינסטגרם נחשב עזיבה ועוקב חדש. זה מתועד ב־README.

## קובצי הנתונים באתר (`site/data/`)
- `meta.json`: `{ count, houses, updated, day, history }`. `count` = עוקבים פעילים, `houses` = אורך ה־registry.
- `r/<2 hex>.json`: `{ "username": houseNumber }` לפעילים בלבד, מחולקים לפי שני התווים הראשונים של sha256(username).
  זה יוצא 256 קבצים, ולחיפוש מספיק לטעון קובץ אחד.
- `list/<NNNN>.json`: מערך של 1000 שמות לפי סדר הבתים (`null` לבית נטוש). משמש את לשונית "תושבים" ואת הלחיצה על בית.

## קוד משותף לדפדפן ול־Node (`site/js/shared/`)
- `sha256.js`: מימוש SHA-256 ב־JS טהור. כך אין תלות ב־`crypto.subtle`, שלא בטוח שקיים בדפדפן של אינסטגרם.
- `username.js`: `normalize(input)` מקבל `@name`, `name` או קישור פרופיל (כולל `m.`, `www.`, `instagr.am`, `/_u/`, query ו־`/` בסוף).
  הפלט באותיות קטנות, רק `[a-z0-9._]` ועד 30 תווים, או `null`.
- `layout.js`: פריסת מגרשים דטרמיניסטית עם seed קבוע ועד 200,000 מגרשים. הפריסה "קפואה" בעזרת בדיקת checksum, כך ששינוי לא מכוון ייכשל בבדיקות.
  - **רשת:** בלוקים של 2×6 מגרשים עם רחובות ביניהם. הים במערב. ציוני הדרך תופסים בלוקים שמורים במרכז.
  - **סדר המילוי:** הבלוקים ממוינים לפי מרחק מהמרכז ועוד רעש, כך שהכפר גדל החוצה בצורה אורגנית.
  - **רחובות:** כל מגרש פונה לרחוב. הרחובות מחולקים לקטעים, ולכל קטע יש שם. השמות מחולקים לפי סדר ההופעה: שילוב של סוג רחוב (שדרות/רחוב/סמטת/דרך/כיכר) ושם (הטחינה, הפיתה, הזית העתיק…), ואחרי שנגמרים הצירופים מוסיפים ב', ג'…

## האתר
- **מבנה:** `site/index.html` עם ES modules, בלי שלב בנייה. Three.js ו־OrbitControls מוחזקים ב־`site/vendor` (רישיון MIT) ונטענים דרך import map.
- **טעינה:** מסך טעינה עם בדיחות יבשות מתחלפות.
- **כותרת:** "תושבים: X · יום Y לכפר".
- **ניווט תחתון למובייל:** חיפוש, הבית שלי, תושבים, עוד.
  - **חיפוש:** מנרמל את הקלט, מחשב hash, טוען את הקובץ המתאים ומחפש בו. אם נמצא: רחוב, מספר בית, מעוף מצלמה, שמירה ב־localStorage וכפתור שיתוף.
    אם לא נמצא: טקסט ביורוקרטי ("הבקשה הועברה לפקיד, שנמצא בהפסקה").
  - **הבית שלי:** הבית שנשמר בדפדפן. אם אין, הפניה לחיפוש.
  - **תושבים:** רשימה בדפים של 1000, כל שורה עם בית ושם, ולחיצה מעיפה את המצלמה לבית.
  - **עוד:** איך מקבלים בית, נוהל העירייה, הערת פרטיות (רשימת העוקבים ציבורית) וקרדיטים.
- **קישור עמוק:** `?u=name` פותח ישר בית.
- **מצב דמו:** `?demo` טוען את הנתונים מ־`data-demo/` (נמצא ב־gitignore) לתצוגה מקומית בלבד.
- **ללא נתונים:** אם `count` הוא 0, מוצגת הודעה "הכפר עוד לא נוסד, אבו־ג'מיל מחפש את החותמת".

## הכפר בתלת־ממד
- **בתים:** InstancedMesh עם 3 סוגים, וצבעים לכל בית (instanceColor). בית נטוש נצבע אפור.
- **שאר העולם:** קרקע, רחובות ומדרכות (InstancedMesh), וים במערב עם תנועה עדינה.
- **ציוני דרך פרוצדורליים:**
  - החומוסייה הגדולה, עם צלחת חומוס ענקית על הגג
  - תנור הטאבון
  - חורשת זיתים
  - הגשר ("ג'יסר")
  - בניין העירייה עם שלט "סגור"
  - מגרש כדורגל
  - סירות דייגים
- **אינטראקציה:** OrbitControls. לחיצה על בית מחשבת את מספר הבית מתוך instanceId ומציגה את הכרטיס שלו.
  בית שנמצא מקבל סמן קופץ, והמצלמה עפה אליו.

## הטון
עברית מדוברת עם טעם ערבי קל (יאללה, יעני, אהלן וסהלן, ח'לאס, שוויה שוויה). הצחוק הוא על הביורוקרטיה, ולא על התושבים או על הדת:
- פקיד העירייה הדמיוני, אבו־ג'מיל, תמיד בהפסקה
- ציוני דרך של חומוס ופיתה
- עצי זית

## כלים
- `npm run update -- <file> [--force] [--push]`: הפקודה הראשית.
- `npm run demo`: מייצר 30,000 עוקבים מומצאים ל־`data-demo/`.
- `npm start`: שרת סטטי מקומי, בלי תלויות.
- `npm test`: מריץ `node --test`.
- `npm run vendor`: מעתיק את three מ־node_modules ל־`site/vendor`.

## בדיקות
- sha256 מול `node:crypto`
- normalize
- parse-export: הפורמט הישן, הפורמט החדש (title/href), עטיפת `relationships_followers`, zip, וייצוא HTML שנדחה בהודעה ברורה
- כללי ה־registry
- emit: תוכן הקבצים
- layout: checksum, אין חפיפות, אין מגרשים בים או על ציוני דרך, שם רחוב לכל מגרש
- בדיקה ויזואלית: צילום מסך עם Chrome headless
